El modelo y su justificación

Variables, parámetros y unidades

  • C(t): concentración del contaminante [mg/L], variable dependiente.
  • t: tiempo [h], variable independiente.
  • V = 1000 L: volumen constante del tanque.
  • Q = 100 L/h: caudal de entrada y de salida.
  • k = Q/V = 0.1 h⁻¹: tasa de dilución.
  • C₀ = 50 mg/L y umbral seguro de 5 mg/L, ambos hipotéticos.

Supuestos

  • Mezcla instantánea y homogénea en todo el tanque.
  • El agua de entrada no contiene el contaminante.
  • Contaminante conservativo: sólo sale por el flujo, sin reacción ni sedimentación.
  • Caudal y volumen constantes durante toda la simulación.

Solución exacta, paso a paso

  1. Balance de masa con entrada pura: V·dC/dt = Q·0 − Q·C, es decir dC/dt = −k·C con C(0) = C₀.
  2. Separar variables (C > 0): dC/C = −k dt.
  3. Integrar: ln C = −k·t + A, luego C(t) = eA·e−k·t.
  4. Con la condición inicial, eA = C₀, así que C(t) = C₀·e−k·t.
  5. Comprobación por sustitución: C′(t) = −k·C₀·e−k·t = −k·C(t) ✓ y C(0) = C₀·e⁰ = C₀ ✓.
  6. Tiempo al umbral: C(t*) = Cs da t* = ln(C₀/Cs)/k.

Heun (RK2 predictor-corrector)

C* = Cᵢ + h·f(tᵢ, Cᵢ)
Cᵢ₊₁ = Cᵢ + (h/2)·[f(tᵢ, Cᵢ) + f(tᵢ₊₁, C*)]

Error global proporcional a h².

Runge-Kutta de orden 4

k₁ = f(tᵢ, Cᵢ); k₂ = f(tᵢ+h/2, Cᵢ+h·k₁/2)
k₃ = f(tᵢ+h/2, Cᵢ+h·k₂/2); k₄ = f(tᵢ+h, Cᵢ+h·k₃)
Cᵢ₊₁ = Cᵢ + (h/6)·(k₁+2k₂+2k₃+k₄)

Error global proporcional a h⁴.

Limitaciones

Es una simulación educativa con parámetros supuestos, no una predicción comprobada ni una autorización para consumo. Un tanque real tiene zonas mal mezcladas y el contaminante puede reaccionar o sedimentar; decidir que el agua es potable exige análisis de laboratorio. El método numérico sólo reduce el error de cálculo: no corrige los errores del modelo.
